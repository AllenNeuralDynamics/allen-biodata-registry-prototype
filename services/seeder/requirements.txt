# Runtime dependencies for the Sample-Data Seeder Lambda.
#
# pg8000 is pure-Python (no libpq native bindings), which keeps the
# deployment package fully portable — `terraform apply` from any
# developer workstation produces a working Lambda zip without
# platform-specific wheels or Docker-based builds. Mirrors the
# migration-runner Lambda's choice for consistency.
#
# boto3 is provided by the AWS Lambda Python 3.12 runtime, so we
# intentionally do NOT pin it here — the runtime SDK already exposes
# `s3.get_object` and `rds.generate_db_auth_token`, which are the only
# AWS APIs the seeder uses. Bundling boto3 would just inflate the
# deployment package and risk version drift.
#
# We deliberately do NOT use `ijson` for streaming JSON parsing here:
#   * the 10% sample is well under 1 GB, fits comfortably in Lambda
#     memory at 1024 MB,
#   * `json.loads` on a single bytes payload is markedly faster than
#     ijson for our throughput (~10k records),
#   * adding ijson means another non-stdlib dep in the deployment zip.
#
# If a future iteration needs the full 7 GB snapshot, switch to
# Streaming-S3 + ijson and bump the timeout / memory accordingly.
pg8000>=1.30.0,<2.0.0
ijson>=3.2.0,<4.0.0
