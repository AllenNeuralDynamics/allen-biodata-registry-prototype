# Runtime dependencies for the Schema Migration Runner Lambda.
#
# pg8000 is pure-Python (no libpq native bindings), which keeps the
# deployment package fully portable — `terraform apply` from any
# developer workstation produces a working Lambda zip without
# platform-specific wheels or Docker-based builds.
#
# boto3 is provided by the AWS Lambda Python 3.12 runtime, so we
# intentionally do NOT pin it here — the runtime SDK is always recent
# enough for `rds.generate_db_auth_token`, and bundling it would just
# inflate the deployment package and risk version drift.
pg8000>=1.30.0,<2.0.0
