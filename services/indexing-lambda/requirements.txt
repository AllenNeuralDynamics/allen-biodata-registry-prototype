# Runtime dependencies for the Indexing Lambda.
#
# Unlike most business Lambdas, the Indexing Lambda does NOT consume
# the shared layer's psycopg/aind-data-schema. Reasons:
#   * pymongo + opensearch-py + requests-aws4auth are unique to this
#     Lambda and bundling them in the shared Layer would balloon the
#     Layer image used by every other business Lambda.
#   * The Indexer connects to Aurora as a privileged BYPASSRLS role,
#     not via the shared Layer's RLS-aware aurora_connection helper.
#
# boto3 is provided by the Lambda Python 3.12 runtime; bundling a
# second copy doubles cold-start unzip cost and risks version drift.

pymongo>=4.6,<5.0
opensearch-py>=2.4,<3.0
requests-aws4auth>=1.3,<2.0
psycopg[binary]>=3.1,<4.0
